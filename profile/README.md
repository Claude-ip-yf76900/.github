<p>Claude纯净住宅IP推荐这件事，脱离使用强度谈都是空话。低频验证、中频日常、高频批量，三种强度对应的方案完全不同，硬推一种给所有人，最后一定是有人觉得贵、有人觉得不够用。</p>

<p>低频场景，比如一周用几次、每次几十个请求。这种强度下，共享出口完全够用，重点放在归属核对和随时可换。为这种场景买独占，钱花得不值。</p>

<p>中频场景，每天都要用，但并发不高。这时候稳定性变成第一位，共享方案要挑那些出口没有被过度分配的，宁可单价高一点。</p>

<p>高频场景，多会话并行、长时间在线。这种强度下必须看独占程度和并发上限，共享出口的问题会被放大，一次牵连就可能影响整天的工作。</p>

<p>分层之后再看验收。不管哪一层，验收项目是一样的：归属三项一致、会话内出口不变、观察期内不掉线。区别只在容忍度，低频可以宽松些，高频必须严格。</p>

<p>还有一个维度是变更成本。有些方案换一条线路要重新走一遍配置，有些点一下就行。低频场景这个差异无所谓，高频场景一周换两次，累计起来就是很大的时间开销。</p>

<p>预算怎么定？建议先把一个月因为线路问题损失多少时间估出来，再拿这个时间和方案价差比。绝大多数情况下，为稳定性多付的那部分，比返工便宜。</p>

<p>推荐时一般给两个方向而不是一个答案：一个偏保守，稳但贵；一个偏经济，能用但要接受波动。让人自己按场景选，比替他决定更负责。</p>
